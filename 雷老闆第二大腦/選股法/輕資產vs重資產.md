# 輕資產 vs 重資產(決定本益比天花板的關鍵維度)

> ← [[大猩猩選股法]]。估值前**先分輕/重資產**,否則本益比會嚴重誤判。

| | 輕資產 | 重資產 |
|--|--------|--------|
| 例 | 軟體/雲端/訂閱(FAANG)、IP、平台 | 塑化、重電、鋼鐵、航運、半導體**製造** |
| 資本支出 | 小,**擴產迅速** | 大,廠房建置 **>1 年**,無法快速增產 |
| 毛利率 | **普遍 >30%** | 較低、隨景氣波動 |
| 本益比 | 市場給得**高**(成長快爆發力強) | 給得**低**(循環、資本密集) |
| FCF 特性 | 通常正(不燒設備) | **擴產期常為負(正常,非地雷)** |

## ⭐ 兩個呼應
- **與 [[自由現金流]] 三級呼應**:重資產股擴產期負 FCF 是常態(🟡),不可套輕資產標準錯殺
- **與 [[本益比擴張]] 呼應**:拿輕資產高本益比套重資產(或反之)會嚴重誤判
  - 例:台燿是半導體材料 = 偏重資產,不能用軟體股本益比想像

## 輕資產新商業模式案例
- 台灣較少:尚凡5278(交友直播)、綠界6763(第三方支付)、麗豐-KY 4137(醫美)、美而快5321(網紅)
- 詳見 [[尚凡5278]] — 成本固定 + 營收靠流量黏著度 → 營收一拉獲利槓桿極大

## NASDAQ 趨勢
- 軟體股/訂閱制漸成主流,倚靠品牌/高市占/高黏著度,資本支出小但營收成長快
