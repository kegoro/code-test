# 本益比擴張 — 飆股的另一半引擎

> ← [[大猩猩選股法]]。EPS 成長(見 [[六大財務指標總覽]])只是一半,本益比擴張才是爆發力來源。

## ⭐ 核心公式
> **本益比 × 預估 EPS = 合理股價**

- EPS 提升 → 股價線性上升
- 本益比同時提升 → 股價**指數放大** → 這才是飆股

## 本益比為何會被法人調高
四大特徵任一出現 → 市場對未來成長性重新定價 → 給更高本益比:
- **新客戶/新市場** → 成長天花板被打開
- **新產品/新技術** → 競爭者少、稀缺性 → 資金湧入有限標的
- **新政策** → 訂單長而穩、政府背書 → 法人敢長抱
→ 完整四特徵見 [[大猩猩四大特徵]]

## ⚠️ 天花板受資產屬性限制
- 本益比天花板由 [[輕資產vs重資產]] 決定
- 重資產(循環股)再好也給不到軟體股的高本益比
