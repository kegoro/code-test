# 尚凡 5278 — 輕資產直播(獲利槓桿範例)

> 對應 [[輕資產vs重資產]] 輕資產 + [[大猩猩四大特徵]] 新商業模式。

## 為何輕資產
- 直播 = **成本固定、毛利高**
- 「斗內」貼圖(汽車=888、火箭=8888,火箭毛利是汽車 10 倍)對平台**只是 1 張貼圖成本**
- → 營收提高 EPS 就快速成長

## 軌跡
- 愛情公寓起家 → 2014 BeeTalk 衝擊 EPS 崩 → 2017 iPair 加直播逆轉
- 連續數月營收 +30% → 2018/6 約 **65 元**進場 → 2019/3 突破 **200** 出場
- 本益比扶搖直上

## ⭐ 輕資產判讀
- 成本結構固定 + 營收靠流量/黏著度 → 營收一拉,獲利槓桿極大
