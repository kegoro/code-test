# 指標二:毛利率、營益率 — 看公司競爭力

> ← [[六大財務指標總覽]]

## 公式
- **毛利率 = 毛利(營收 − 營業成本) ÷ 營收**
  → 反映產品成本 vs 收入;有獨特優勢/議價力 → 毛利率越高、競爭力越強
- **營業利益率 = 營業利益(營收 − 營業成本 − 營業費用) ÷ 營收**
  → 扣掉場地/水電/廣告/研發/折舊 → **直接看本業獲利能力**

## 重點
- **服務業、IC 設計** → 營益率是**必須關注**的重點
- 眉角:折舊費用列「營業費用」或「營業成本」各家不同,會影響高低,需查證

## 關聯
- 與 [[營收]] 搭配看:營收增 + 毛利率同步升 = 真成長(否則 [[雷老闆5原則|過水單]]假業績)
- 高毛利產品占比 → [[營收]] 產品組合段
