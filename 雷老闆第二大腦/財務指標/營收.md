# 指標一:營收 — 看出產業趨勢

> ← [[六大財務指標總覽]]

## 本質:營收 = 價格(P) × 出貨數量(Q)
P、Q 都繫於供需 → 看營收本質是**看供需**。
- **需求不振**(需求左移)→ 價量雙跌 → 雙重打擊(最慘)
- **供過於求**(供給右移)→ 價跌量增,一增一減 → 影響可能不大

## ⭐ 月成長率 / 年成長率(最常用)
- 月成長率 = vs 上月;**年成長率(YoY) = vs 去年同期(較客觀**,排除淡旺季)
- **買訊**:營收連續 2~3 個月 **YoY >10%** → 可能出貨大訂單/研發收割
- **賣訊**:月成長率連續減少(尤其連 3 個月月衰退)→ 公司走下坡
  - 案例 創惟 6104:2022/4 起連 3 月月衰退 → 股價 6 月轉弱

## 季底效應與陷阱
- 季底作帳者 → 3/6/9/12 月為單季最高
- ⭐ **強訊號**:次月(4/7/10/1)營收更好 = 擺脫慣性、進入新成長期
- **別被騙**:季底後月增轉負,跟去年同期比 YoY 仍雙位數 = 仍正向
- **農曆年**:1+2 月合計與去年同期比,消除工作天數偏差

## ⭐ 產業淡旺季濾鏡(圖表2-20)
> **淡季衰退=正常;旺季衰退=真警訊**

| 產業 | 旺季 |
|------|------|
| 貨櫃航運 | 7–10 月 |
| 航空/晶圓代工/電子零組件/手機/紡織 | 下半年 |
| 水泥/鋼鐵 | 第4季 |
| IC設計 | 第2~3季 |
| 汽車零組件 | 第4季~隔年第1季 |
| 化學 | 第2季 |
| 橡膠 | 5–7月、11–1月 |
| 金融 | 第4季 |

- 蘋果 PCB 鏈(臻鼎4958/台郡6269):5月起拉貨 → 高峰10/11月 → 降至隔年3-4月

## 同業/族群性(買進更有信心)
- 族群性:公司業績好 → 上游原料廠同步出貨好
- AI 伺服器成長 → 電源/機殼/記憶體/散熱連帶成長(時間有先後)
- 呼應 [[合約負債]]「產業普查」找同鏈標的

## 產品組合
- 同營收下,**高毛利產品占比提升 → 實際獲利越高 → 股價易漲**(見 [[毛利率營益率]])
- 案例:貿聯-KY 3665(消費電子→工業/車用/資料中心)、信邦 3023(利基線材毛利>25%)
