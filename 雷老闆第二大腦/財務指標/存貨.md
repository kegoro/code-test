# 指標四:存貨 — 帶領先性質,財報菁華

> ← [[六大財務指標總覽]]

## ⭐ 核心:存貨的加分/扣分,由「景氣方向」決定
- **景氣上升 → 存貨增加 = 加分**(2021 缺貨王道,有貨可賣 = 未來營收有空間)
- **景氣下行 → 存貨增加 = 扣分**(2022 需求急凍,高存貨變生產過剩 → 降價求售 → 侵蝕毛利)

→ 看存貨**不能只看數字高低**,要先判斷產業景氣在升或降。

## 實戰案例
- [[中鋼2002]]:2021 Q1 起每季存貨往上 → 股價 2021/4 急漲,印證「景氣上升存貨=加分」
