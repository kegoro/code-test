# 指標六:自由現金流量(FCF) — 檢視公司槓桿

> ← [[六大財務指標總覽]]。長線方向球 / 降風險用。

## 公式
- **FCF = 營業現金流量(OCF) − 資本支出(CAPEX)**
- 「自由」= 公司能自由運用的現金,觀察會不會入不敷出

## 為何重要(EPS 賺錢 ≠ 有現金)
- EPS 可能只是「拿到發票就先認列」,錢還沒收到 → 要資本支出時現金軋不過來
- 穩健 FCF 才扛得住意外;長期大額資本支出 → 沒餘錢配息 → 長期壓抑股價

## ⚠️ FCF 不要「一票否決」(2026-06-14 修正)
> 原寫「FCF 長期負 = 淘汰」太武斷,會**錯殺擴產期成長股**。

FCF 為負有兩種,意義相反:
- 🟡 **進攻型負 FCF**:OCF 正(本業賺真錢)+ 大舉 CAPEX 擴產 → **是好事**
  - 例:台燿6274 為 M8 狂蓋產線,短期 FCF 必負 = 進攻不是危險
- 🔴 **失血型負 FCF**:OCF 也負(本業沒收到現金)+ 靠借錢硬撐 → **這才是地雷**

## ⭐ 三級判斷依據(客觀呈現,不自動淘汰)
- 🟢 OCF 正 + FCF 正 → 又賺錢又有餘裕
- 🟡 OCF 正 + FCF 負 → 擴產期(判斷是否在投資未來)
- 🔴 OCF 負 → 真警示(本業沒收到現金)

→ **真正的紅線是 OCF,不是 FCF**
