# 指標三:EBITDA — 本業獲利能力

> ← [[六大財務指標總覽]]。息稅折舊攤銷前利潤,適合找「被埋沒的鑽石」。

## 公式
- **EBITDA = 稅後淨利 + 利息 + 稅額 + 折舊與攤銷費用**
- 稅後淨利 = 營業利益 + 業外損益 − 稅額
- 把減項加回 → 算出「不支利息/稅/折舊攤銷前」盈利能力,更貼近真實營運

## 兩個使用重點
1. 找出**被低估**股票
2. ⭐ **必須與同業比較**才有參考價值(受債務/各國稅率/資本支出折舊影響)

## 關聯
- 同業比對邏輯同 [[營收]] 族群性
- 找鑽石 → 接 [[大猩猩選股法]]
