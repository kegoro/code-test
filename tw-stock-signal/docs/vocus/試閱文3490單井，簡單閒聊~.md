# 試閱文:3490單井，簡單閒聊~

URL: https://vocus.cc/article/69d5f396fd897800019e101c

左邊是一年前的川普關稅時期，這種就是很弱的，隨市場反彈，然後就跟某些男生一樣站不起來，我是說膝蓋不好，想歪是你家的事。
量縮下跌到川普關稅的低點附近，就不再下跌了，然後突然出量(相對於之前的小量)，價格拉升、噴很多。
拉升到高點之後，快速量縮、下跌，開始相對高檔的橫向整理，現在我們可以確定川普關稅應該就是長期的底部了。
高檔箱型整理的階段，尤其是中後期，可以發現他經常能站到全部均線之上，只要跌下來，就被快速拉上去，是誰莫名其妙這麼愛拉拔他。
有一個看起來就像是被刻意設定的防線，也就是箱型的底部。只要碰到箱型的下緣，就被V上去。重複出現，就值得注意。對於一個大戶持股這麼低的股票，這個看起來就像有人在圍事。
中間幾次出量，外資與融資都有出力(同時或個別出力)，外資隨著每一次的拉升、下跌後，持股慢慢在增加。ㄟ，外資在外面最近一個月不是賣了一兆，跑來這邊幹嘛?
對了，之前協助股價維持在箱型整理區間的融資，近期也有跑來一些。
最近他曾經突破箱型的上緣，成交量也有在增溫，只是都沒有有效上去。
240扣抵未來都在相對低價區。
大戶持股真的不多，只有20%、20%、20%，要是再高一點就可以更認真聊。
大戶是在高檔整理的期間增加的，大約有6%的持股停在這個狹小的區間，成本大約就在24、25、26這邊吧，6%是一筆大錢。神經，便宜的時候不買，高檔才在買，還不讓他跌下去，應該是有一種錢太多沒處花的病。
然後捏，有一群很奇怪人，在228中東戰爭後跑來，看起來也像有病，大家都在離開市場的時候，量縮捏，戰爭捏，不確定捏，跑來幹什麼?錢太多嗎? 一定是有錢太多沒處花的病。
對了，那段時間股東人數增加，但是散戶減少，格友柯南應該知道要往哪裡找更多的線索吧?是買零股準備領紀念品的，還是躲起來的那種?
外資增加持股的初期，上方橘線大戶沒有變化，但是股價就在箱型整理區間，跌不下去，有沒有很奇怪。你如果是外資，幹這種事情，如果沒有正當理由，不被長官釘在牆壁，你跟我姓。
後期外資增加，大戶也跟著增加，股價也底底高了起來，還突破箱型區間測試，有沒有一種交換完了甚麼神祕東西，開始拿到某種神秘力量的感覺。
主力在箱型整理區間，買強天比較多，最近則是一直買。不知道要幹嘛~
大戶持股還很低，但是有持續進來的外資，有可能是重新合流的融資，有突破箱型整理區間的企圖，有莫名其妙的一群神經病跑來，成交量開始增溫....。
