# 馬可孛羅《Mystery World》

URL: https://vocus.cc/article/66f763bcfd897800012dbdd8

另外，那個行李箱男孩，一下子出現在《ＥＣＨＯ》一下子又有頭無尾地出現在這個系列裡，一本書出現在兩個系列這種事情，我覺得出版社無論講起品味或者商業形象的堅持，連差強人意這種委婉的責怪都受不起，就是一個單純的討厭了。

我記得有一次在書展，我跟出版社的人抱怨過這種情況（別個出版社），他們還敢跟我嘻皮笑臉地懟回：不然怎麼賺錢？

嗯，馬可孛羅要堅持自己的品味，寧可不要出版，也不要一書二出的搞的風格跟品味都顛三倒四的。

但是，封面設計的漂漂亮亮的真不錯，還有，千萬別在礙於人情壓力搞的這套書的內涵亂七八糟了！拜託拜託了！
