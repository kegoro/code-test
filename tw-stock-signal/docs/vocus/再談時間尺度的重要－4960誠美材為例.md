# 再談時間尺度的重要－4960誠美材為例

這是他一年的資料，

是有一點東西，但好像有點無聊。

成交量不高，

外資買買賣賣，

大戶慢慢增加，

散戶慢慢減少，

好像可以看，又不知道怎麼看。

你以為這樣就完了嗎?

這是他的5年周線(玩股網股權頁，可以點選周線觀察長周期的股權變化)，

從2021年5月到現在，大戶增加了30%，

30%，是一筆很大很大的錢。

那些錢擠在一個小小的價格區間，1年、2年、3年....

這中間，他們不去伺服器、不去記憶體，它們停在這裡。

他們在一檔成交量很低的個股，默默地吃了30%的股權。

我覺得非常的奇怪。

最近一年日線

最近一次上攻，沒人追價，

量縮下跌消化賣壓，

目前爬回前方整理區。

外資也慢慢偷買回來。
