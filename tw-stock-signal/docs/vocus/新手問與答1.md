# 新手問與答1

URL: https://vocus.cc/article/694ca867fd89780001437004

暫時忘記你所學的一切知識，放棄固執，嘗試接受新思維。閱讀時，假裝自己就是控盤者、你是超級有錢人，先只用錢的角度思考，嘗試理解控盤者的想法。(順序可以是先用錢思考後覺得籌碼面不錯，再回到你擅長的產業、財務面找線索)
每一篇個股文章，即時是舊文也很重要，觀察技巧都在各篇文章中。

問：要如何像M哥一樣能看圖說事情？

答：多看多練習。從模仿開始也很好。

問：你對技術分析的看法？

答：技術分析對我只是輔助，你們很少看我談技術分析，我優先關心的永遠都是量能、趨勢與錢的想法。當然，你還是要懂一點支撐、壓力、大紅K、大黑K、十字線、缺口這些基本概念。

問：M哥有看分點嗎？

答：很少，只要時間拉長，籌碼真實的企圖就不好藏。主力躲在台北或桃園，康和或元大，我不在意，我只在乎能不能看清楚大錢的軌跡與想法。

問：有沒有你看不懂的個股?

答：有，看不懂就跳過，我只在自己擅長的領域賺認知以內的錢。冷眼看、客觀看，不要為自己想買或賣的股票硬從線圖找理由。

問：我如果稍微看懂了，要如何開始？

答：小白先找好2-5個標的，從模仿開始，用零股在B買他，當學費，不要輕易離開他，花久一點的時間跟隨觀察記錄。並不斷複習我的文章，檢視歸納調整出你的模式。已經有很多人用這個模式練習出能力。

問：看到多檔符合條件的標的，不知道怎麼下手?

答：新手找成交量不要太低的，至少找日成交量2,000張以上或更多的、大戶持股40%、45%以上的，最好是你曾經有成功經驗模式的，不斷練習積累能力。成交量太低，出事情不好跑喔。

問：投資最需要的是什麼？

答：清楚自己為什麼買他。

問：你會因為錯過某檔個股懊悔嗎?

答：不會，我手中隨時觀察20檔左右的長多標的，它們會輪流烙賽，我總是有新的B可以評估。

問：遇到個股有疑慮你會怎麼做？

答：時間拉長，回頭看筆記確認當時愛她的條件還在不在，這樣你的心情通常會穩定很多，不會被嚇住。

問：為什麼會上網寫文章？

答：對土城廣福福德宮土地公、土地婆承諾要傳播知識並宣揚神威(海山捷運站步行5分鐘，捷運站周邊廣場非常漂亮)。以及讓孩子理解3C的真實用途是工具，不僅是遊戲與影音。

問：為什麼對部分文章改採付費制?

答：留下學習者與同行者。有人願意花時間認真閱讀作品並有共鳴，對作者才是真鼓勵。另外，不願意付出時間學習，只想看號碼，很難期待能力會成長或有回報，原因是因為號碼仔缺乏認知，不知道自己為什麼要買。

問：為什麼一個月268，別人都很恐怖！

答：希望能讓小白少走彎路。268是要讓你有一點點小肉疼，希望你能多讀幾次文章，才可以真正理解我及籌碼的訊息。另外考量到訂閱玩股網也要199，所以當時跟孩子討論後就酌收268。
