# *不要跟散戶站在一起(必讀)

URL: https://vocus.cc/article/693ea531fd8978000151a3ad

注意看每個框框裡面的箭頭方向。

一、真正的事實：

1. 紅色框框，股價在上漲，大戶(紅柱)在買，散戶(綠柱)在賣。

2.綠色框框，股價在下跌，大戶在賣，散戶在買。

3.每個框框都是這樣喔，此模式在有點成交量的股票都可以重複發現。

(如果發現與上述情形不同的情況持續發生，就要注意可能會有轉折)

二、說明：

1. 大戶的資訊相對完整，他們經常可以看到未來的好壞，因此會預先增持或減持。

2. 散戶則因欠缺完整的資訊，股票上漲時，沒有新聞，沒有可以相信的理由，是不敢下手買入的。散戶反而是在看了很多美好的新聞與小作文後，在股價終於下跌的階段才敢進場買入，還會暗喊「來了，機會終於來了，公寓換透天的時間到了！」

3. 但股價一路往下掉，散戶會在終於熬到解套或小虧時，連滾帶爬的賣掉，然後告訴自己，一張不賣奇蹟自來，然後眼巴巴的看著股票飛上去。

然後，散戶賣、大戶回買，無限循環。上面的圖是不是一直重複上演相同的戲碼?

 三、統合建議：

1. 追高殺低只是散戶的個別短期決策。我們常聽到散戶追高殺低賺不到錢，這是指「個別散戶」的「短期決策」經常會發生錯誤。

2.時間拉長，散戶們最終的命運集合是「一路漲一路賣；一路跌一路買」。

(1)散戶的集體行為在「上漲的過程」，因為「資訊欠缺、對未知恐懼」，有風吹草動，小賠就跑、解套就跑、小賺也跑，還會安慰自己「賺2%可以漢堡加大，比定存強多了」，得了一種害怕漲太多的病。

(2) 散戶在觀察的股票「漲多大跌後」，因為受到各種資訊曾編織的美夢影響，會一路跌、一路買，還會認為自己價格買得漂亮，但卻看著股票一路往下跌，最後受不了認賠殺出，或在解套後就連滾帶爬離開，然後看著它再次飛上去。

3. 你要面對這個現實，承認自己總是這樣，並沒有聰明到那裡。

4. 從今天開始不要隨便跟綠柱的散戶站在一起，他們是壞朋友。去找紅柱大戶「呈現持續增加趨勢」的標的研究。

四、其他參考案例:

台積電，多數的時候也是這樣。藍色箭頭的地方出現違反慣性的連續狀況，後來就跌了一段。

中信金，也是符合相同的慣性。
