# 為什麼一定要找趨勢正確的標的，學習觀察6125廣運

URL: https://vocus.cc/article/693bc1b2fd897800018c0b7e

一個空頭（下山）的標的，如果沒有趨勢轉變的契機，我們根本不會知道他的底部在哪裏。以1301台塑周線為例，很多人基於過去的信仰，在他下跌的過程，不斷的「攤平」，即使到現在，台灣的經濟成長率不斷創高，那些在山頂或山腰的學長姐一點也感受不到，因為他們搭的是下山的車。 

親愛的，我必須告訴你，除了時間成本以外，在沒有轉多的「跡象」或「機會」就貿然進場，那是很危險的事情。股價會呈現「長期下跌趨勢」一定是有原因，錢比我們聰明，會「趨吉」也會「避凶」。

你可以怎麼做？

 我只碰多頭或是有機關會轉多頭的個股 

前文有提到，一個標的不會沒有理由就從長空（240日均線下彎）轉變到長多(240日均線拉平後上揚)。你要堅信，不會有人「沒理由」就持續砸大錢讓個股的長期趨勢發生改變。你想想，大戶一砸錢讓股價上揚，上面套牢的學長姊就會連滾帶爬的賣出來，那是很大的賣壓，大戶又不是阿彌陀佛，空轉多都需要很長時間的準備與投入。 

所以，我們可以選擇已經有人砸錢且有機會(或跡象)發生改變的個股開始學習追蹤，等跡象或機會更明確的時候再從半山腰搭便車參與，一是可以降低風險、二是減少等待的時間。

 我隨便抓一個上台舉例，用6125廣運來說明(我刻意找的是一個還需要更多準備的個股，建議你開始觀察它3個月甚至更久)：

他是空頭，橘色的240日均線還在下彎。但是，你為什麼可以開始觀察它?

240日的扣抵值位置跟現在的股價相距不遠。

2.再過約20幾個交易日，240日扣抵就會離開高價、高量區，開始下降。

3.假設未來的股價不變，240日線也會因為扣抵價格不斷地降低，被強迫上彎。

4.四月川普關稅之後，他就不再破底了。

5.曾經2度被拉上全部均線之上，這個至少透露出一種我還沒有要死的心態。

6.在7的階段，爆小量後開始量縮下跌，那是賣壓仍在的狀態。但是，這個階段外資持股開始快速增加(8.1到8.2)，從外資持股斜率可以簡單的看出來，外資心態明顯比過去還要積極。

8.從9觀察，大戶還沒真正開始增加，從10觀察散戶持股略有減少；從11則可以發現股東人數開始明顯下降，這些股票研判是被外資慢慢買走為主。

結論

他是一檔空頭的標的，但是240日扣抵再一段時間就要開始快速下降，他的240日均線有機會被強迫上揚。這段時間觀察到外資不斷買入，不過，他還時間準備，至少也要先站穩120日均線。

無聊是主力(假設有)最喜歡的朋友，因為無聊與恐懼，不堅定的散戶才會慢慢釋出手中的股票，這需要一段時間的上上下下，你還有很多時間可以喝咖啡優雅觀察，但是在240日均線扣抵位置開始要快速下降的時候，你一定要很認真的盯著他。
