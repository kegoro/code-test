# A+B+C深入解析~孤單寂寞賺錢術

假設，你在黃色區域，均線都是下彎的時候進場，高點過不了前高，低點越來越低，進去等待，不知道何時才能看見隧道的盡頭。
在藍色區域，股價不再一直往下跌，股價的趨勢慣性改變了，高點越來越高，低點也越來越高，而且在藍色地帶的中後期，有外資明顯的持續在買他，你要想到為什麼趨勢會改變，要想到外資為什麼要持續買。(在股票的世界，趨勢與慣性是重要的線索)
我們就是要找到裡面有人，而且願意一直出錢讓趨勢改變的有心人。我們要搭大錢的便車，偷偷的跟在他們的屁股後面，成為主力的同伴，這樣才能減少資金等待的時間成本。
股價在橘色區域站上了當時的一年新高，240日線慢慢被拉平、開始有往上翹的跡象。
未來240線的扣抵價格位置都在低價的藍色區域，現在的股價則是在高位的橘色區域，這是有助於長線發展的型態。
我也喜歡「即將轉長多的個股」，除了基期比較低，有籌碼的標的剛轉長多時，容易有甜美的果實。
這是東捷原文2月4日發表時的樣子。
黃色區塊是當時的240日扣抵價格位置，當時再經過一個月左右，240的扣抵價格就要一路往下，只要當時的股價維持不變，240日線就有機會拉平、往上發展。
更何況他在紅色箱型區間整理時，下方已經有持續進場的大錢(即上圖的外資)。
像這種如果能早一點發現，在橘色箭頭，基期較低處，就可以認真評估。下方的箭頭是量縮整理價格不跌，而且是在被刻意設定的低點附近；上方的箭頭則是突破箱型整理區間的位置。
你要記得，空頭個股的上方都是賣壓，沒有特別的原因，不會有人砸錢來改變空頭的趨勢，所以符合A(趨勢正確)且有B1(長期穩定籌碼)的標的，是優先選擇的目標。
A=型態必須是長多或即將長多。

這段經過上面的說明，你應該大致理解了。

B1=要有長期且持續吸籌的過程，或是奇怪的鬼故事。
比如東捷的外資，透過不斷的拉、放、洗、吃，不斷的增加持股。
祕密花園的個股故事，就是在找長期持續吸籌碼的力量，也是這個格子的知識含金量深水區。
B2=只在賣壓很小或賣壓消失，而且B1沒有真的離開才考慮。
B2就是賣壓消失的時刻。賣壓消失就是跌不下去、賣不下去、沒人要賣的時候。
多數的時刻，多頭或即將多頭的股票，就會出現黃色區塊那樣，拉一下、跌一下，不斷清洗浮額、鞏固籌碼。
你仔細觀察黃色區塊前後，下跌的過程都是量縮的，那就是主力要吃貨，刻意製造的賣壓。等到後面量縮價穩，賣壓消失，股價又被拉一小波，然後不斷循環。
長期多頭的股票也常會突然跌很深，我很喜歡觀察跌到120日到240線間糾結的標的。但不是每一檔都會有這種便宜機會可評估，跌深的機會有時一年才2、3次。
例如藍色區域就跌很深，跌到均線糾結，跌到散戶都沒有信心，但是外資的大錢在下跌過程中，並沒有明顯的鬆動，這時你就要想大錢為什麼不跑，他們的錢就不是錢嗎?
M哥的文看久以後，你會慢慢理解不管是黃色還是藍色那種跌下來，跌下來後的量縮價穩、要死不活，常常都只是別人設計的劇本。
外資就在這種漲(出量)、跌(量縮)、價穩(量縮)的循環中，不斷增加持股，這種是典型有人在吸收籌碼的型態。
籌碼一定要配合型態一起看，才能真正看懂主力，也就是你的對手的心思。
