# 《本格MYSTERY‧永恆300》：推理小說愛好者的必讀專書

URL: https://vocus.cc/article/668235ddfd897800019dbf3f

這系列由日本「偵探小說研究會」編纂的專書一共有三本，前兩本分別介紹1987~2002年和2001~2010年間的本格推理小說，本書則介紹2011~2021年間的，去年2023年才在日本上市，是最新一本。




每一年度開章先列出當年度入選作品，再以半頁到一頁的篇幅逐部介紹，把該作品的「內容、看點、成就、相關」等等，都完整呈現在讀者面前——大家知道這有多難嗎？一篇才不到五百或一千個中文字，得把內容篩選再篩選，亦即要有深刻的洞察力，去蕪存菁，加上堅實的筆力、豐厚的素養，才能把這些精華提煉出來，用言簡意賅的文字表達。看似簡單，有自己動手寫過的人就知道有多不容易，所謂「台上一分鐘，台下十年功」，我這個對評論心得算很挑剔的人，也不禁折服於作者群的專業，還有辛苦的譯者張捷！臺灣我讀過類似的是收錄在《詭祕客》年刊情報誌後面的作品選，不過一次只有十來本，本書《本格MYSTERY‧永恆300》可是有三百本！

除了內行看門道，做為撰寫評論和鍛鍊文案力的範本，本書也非常適合讀者來看熱鬧，可以看這三百本中，哪些想看的還沒有中譯，來去向出版社敲碗，像我想看的武俠推理《老虎殘夢》就只有簡體版嗚嗚。（出版社表示：）我個人還會想拿來當參考書，創作者更可以沒事翻翻激發靈感，日本推理作家近十年的心血結晶就在這一本啊，根本是買到賺到！還有專家幫忙整理介紹，連影視、遊戲、漫畫都有專文，書末的作家索引也很好用，可以查找同一作者的書籍。題外話：「特別投稿」那篇是講中國推理不是臺灣推理頗為可惜，但這幾年臺灣作家和出版社的努力是有目共睹，相信必有機會在國外這類代表性情報誌登場。







本書即將於明日開賣，聽說會印很少很少本（有圖有真相），請把握第一時間下單，十年一遇，錯過不再，十年後就又是另一本，也還不知道有沒有人進啦（看看前兩本）。總之，知識有價，想看到更多這種「深度型錄」書籍的，請用新臺幣投票！
