# 要看還原日線?

URL: https://vocus.cc/article/69631c8afd89780001c257e8

上圖為6472保瑞。因為除權息有個大的跳空缺口，以現在的日線看，他跌破了川普關稅的低點。

但是用還原日線看，他還沒跌破川普關稅的低點。看起來的感受是不是有很大的差異?

日月光2025年7月2日除息5.29元，當天出現跳空缺口，下跌4元，-2.75%，跌破前低、60MA快速下彎、20MA下彎。

用還原日線看，當天是上漲3元，+0.93%，也沒有跌破前低，60MA下彎的就沒有那麼大。感受是不是差很多?

簡單說明
原始日線：

會扣除股利，出現「向下跳空」，如果你忘記持股的除權除息日，會誤以為股票怎麼了而驚慌，甚至亂賣股票，錯過後續的填息行情。

還原日線：

會將股利補回股價中，這對我這種比較長時間持股的投資者來說，還原日線才能呈現出股價真實的長期慣性與多空趨勢。

 維持觀察指標的連續性很重要

使用還原日線，才能確保季線（60MA）或半年線（120MA）或年線(240MA)的趨勢線保持平滑，讓我們能更做更精確的判斷，相對不會因為除權息的人為調整而做出錯誤的決策。

建議：

以後要加碼看還原日線。
