## A條件：年線判斷

### 量化標準

| 項目 | 標準 | 來源文章 |
|------|------|---------|
| MA 週期 | **240日均線**（非200日）| 用240線還是200日線 |
| 看法 | 必須使用**還原日線**，消除除權息跳空影響 | 要看還原日線 |
| 長多狀態 | MA240 斜率向上（上彎）| A+B+C深入解析 |
| 轉多狀態 | MA240 由下彎轉平（扣抵值即將下降） | 為什麼要找趨勢正確標的 |
| 空頭排除 | MA240 仍在下彎，即使有外資進場也不碰 | 關於A趨勢的重要性 |

### A條件判斷流程

```
1. 看還原日線的MA240
2. MA240 向上 → 長多 ✅
3. MA240 下彎但扣抵值即將快速下降 → 觀察「即將轉多」 ✅（基期低、甜美果實）
4. MA240 仍下彎，扣抵值未見改善 → 排除 ❌
```

### 扣抵值判斷規則（重要）

- **扣抵值 = 240個交易日前的收盤價**
- 如果扣抵值位置在高價區，而當前股價在低價區 → MA240 還無法上彎
- 當扣抵值快速下降（進入低價區） → 即使現在股價不動，MA240 也會被「強迫上彎」
- **觀察點**：「再過約20幾個交易日，240日扣抵就會離開高價、高量區，開始下降」→ 積極追蹤

### 其他A條件補充

- 股價在全部均線之上且能快速回到均線上 → 強勢訊號
- 站穩120日均線 = 從空頭轉多頭的重要中繼確認
- 高點越來越高 + 低點越來越高 = 趨勢正確的量化確認

## B條件：籌碼判讀

### B1 — 外資（主力大錢）

| 項目 | 標準 |
|------|------|
| 基本條件 | 外資持股呈長期、持續增加趨勢 |
| 強力訊號 | **弱勢環境（大盤大跌）中逆勢買進** = 最強訊號 |
| 典型吸籌型態 | 漲（出量）→ 跌（量縮）→ 價穩（量縮） 循環中持股增加 |
| 大戶持股門檻 | 日成交量 >= 2000張 + 大戶持股 >= 40%（新手基準），45%以上更佳 |
| 排除訊號 | 外資在下跌過程中明顯鬆動（持股下降）→ 不符合B1 |

**外資看法重點**：
- 不在意外資藏身哪個分點，只在乎「大錢的軌跡與想法」
- 時間尺度要拉長（有些佈局跨越數年）
- 大戶持股增加 + 散戶持股減少 = 籌碼流向正確
- 股東人數下降 = 股票被大戶收走（正面訊號）

### B2 — 賣壓消失訊號（進場觸發）

**B2 的定義：跌不下去、賣不下去、沒人要賣的時刻**

| 識別方式 | 說明 |
|---------|------|
| 量縮價穩 | 成交量縮到極致，股價不再繼續下跌 |
| 防守線被守住 | 碰到箱型底部就被V反彈，且重複出現 |
| 突破箱型 | 量縮整理後突然出量突破整理區間上緣 |
| 無聊冷清 | 沒人討論這檔股票，成交量極低 → 主力刻意製造的寂寞 |

**B2 觸發條件（必須同時）**：
1. B1 沒有真的離開（外資持股未見明顯出脫）
2. 賣壓很小或消失（量縮）
3. 在「主力設定的防守線」附近

**不能追高**：B2 是在量縮無聊時進場，不是在爆量上漲時追

### B3 — 融資（散戶指標）

| 情況 | 判斷 |
|------|------|
| 融資快速增加（近5日>5%）| ❌ 排除條件（散戶追高，主力要清洗） |
| 融資穩定 / 略降 | ✅ 正常，籌碼乾淨 |
| 融資與外資同步進場 | ✅ 輔助確認（「合流」訊號，外資帶頭融資跟進） |
| 融資大量 + 股東人數多 | ❌ 籌碼太亂，主力難以控盤 |

## C條件：進場時機

| 標準 | 說明 |
|------|------|
| C1 | 相信人類慾望不止，科技創新需求不停 → 長期向上的基本信仰 |
| C2 | 相信時間的力量，學習用耐心等待 |

### 具體進場條件

**最佳進場點**：量縮到極致 + 價格回穩 + 沒人討論（孤獨寂寞）

```
進場評估流程：
1. A條件確認（MA240 長多或即將轉多）
2. B1確認（外資持股持續增加，沒有鬆動）
3. 等待B2（量縮價穩，賣壓消失，出現防守線）
4. C（耐心等待浪起）
```

**進場位置優先順序**：
1. 空頭轉多頭初期（「即將轉長多」，基期低）
2. 長多股跌至120日-240日均線糾結區（不常見，每年約2-3次）
3. 箱型整理後突破上緣量增確認

**進場禁忌**：
- 不在爆量大漲時追高
- 不在沒有A條件時因為外資進場就買（火車還在下山）
